# The Buyer's Perspective (TBP) Official Website

![TBP Logo](assets/TBPlogoHiRes.jpeg)

**The Buyer's Perspective** is a fast, responsive, and serverless landing page built for India's honest auto and tech review YouTube channel and the *Tech Buddies* podcast.

This project was designed with a "streetwear meets media brand" aesthetic, prioritizing high performance, sleek typography, and a premium dark-mode user experience without the bloat of heavy JavaScript frameworks.

## 🚀 Features

* **Zero-Dependency Architecture:** Built with pure HTML, CSS, and Vanilla JavaScript. No frameworks, no build steps, just instant load times.
* **Dynamic YouTube Integration:** Utilizes the YouTube RSS feed and a free RSS-to-JSON API to automatically fetch and display the channel's absolute newest video drop in the Hero section—requiring zero manual website updates when new content goes live.
* **Serverless Contact Form:** Integrated with FormSubmit to handle "Review Your Car" requests seamlessly without needing a backend server.
* **Responsive Design:** A custom CSS Grid/Flexbox layout with a mobile-first approach, including a smooth mobile drawer navigation and responsive video embed scaling.
* **Performance Optimized:** Achieves near-perfect Lighthouse scores through system fonts, deferred off-screen loading, and optimized asset delivery.

## 🛠 Tech Stack

* **Frontend:** HTML5, Vanilla CSS (Custom Properties, Flexbox, Grid), Vanilla JavaScript (ES6+)
* **APIs:** YouTube RSS feeds, RSS2JSON API
* **Deployment:** Hosted on Vercel
* **Typography:** Inter, Space Grotesk, Playfair Display (via Google Fonts)

## 💻 Local Development

Since the site relies entirely on standard web technologies, there is no setup required. 

1. Clone the repository:
   ```bash
   git clone https://github.com/GMen0n/tbp-website.git
   ```
2. Open `index.html` in any modern web browser.
3. Edit the files and refresh to see changes instantly.
